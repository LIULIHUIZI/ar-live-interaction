# AR Live Interaction

基于浏览器的实时表情识别与 AR 粒子互动原型（v8），通过用户的面部表情触发直播视觉特效。

**在线体验：** https://liulihuizi.github.io/ar-live-interaction/

## 核心功能

- **微笑下雨：** 识别微笑表情，触发动态雨滴效果。
- **大笑烟花：** 识别张嘴大笑，触发随机烟花绽放。
- **头部碰撞：** 烟花完整绽放后，散落粒子与近似头部轮廓发生物理碰撞；未接触的粒子自然下落。
- **视觉增强：** 支持 24% 暗色蒙层开关，让烟花在不同背景下更加清晰。

## 技术实现

- **MediaPipe Face Landmarker：** 人脸关键点检测与表情特征识别。
- **HTML Canvas 2D：** 雨滴、烟花及粒子动画渲染。
- **JavaScript 粒子物理：** 实现重力、散落运动及头部轮廓碰撞。
- **GitHub Pages：** 静态页面部署，无需后端服务。

## 性能优化

重点控制实时识别与粒子渲染的计算开销：

- 限制同时存在的粒子数量，避免密集烟花造成性能波动。
- 仅在烟花散落阶段执行头部碰撞检测，减少无效计算。
- 采用头部区域预筛选，降低逐粒子碰撞判断的成本。

## 本地运行

在项目目录下执行：

```bash
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080/`，授权摄像头后即可体验。

首次运行需要联网加载人脸识别模型，建议使用 Chrome 浏览器。

## 已知限制

目前属于浏览器端交互原型。头部轮廓采用二维近似，表情识别效果受光照、摄像头角度和设备性能影响，尚未进行跨设备性能基准测试。
